# 🏊 Swimming Sifu

Your comprehensive guide to mastering swimming - from beginner to world class!

## 🌟 Overview

Swimming Sifu is a web application designed to guide swimmers at every skill level. Whether you're just learning to float or training for the Olympics, this app provides structured guidance, training schedules, and expert tips.

## 🎯 Features

- **5 Skill Levels**: Beginner, Intermediate, Pro, Elite, and World Class
- **Comprehensive Guidance**: Each level includes:
  - Clear goals and objectives
  - Skills to master
  - Training schedules
  - Sample workouts
  - Expert tips
  - Performance metrics
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Navigation**: Easy switching between levels with keyboard shortcuts
- **Modern UI**: Beautiful gradient design with smooth animations
- **Progress Tracking**: Remembers your last viewed level

## 🚀 Getting Started

### Option 1: Open Directly
Simply open `index.html` in your web browser to start using the application.

### Option 2: Using a Local Server
For the best experience, use a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## ⌨️ Keyboard Shortcuts

- **Arrow Keys (← →)** or **A/D**: Navigate between levels
- **Number Keys (1-5)**: Jump directly to a level
  - 1: Beginner
  - 2: Intermediate
  - 3: Pro
  - 4: Elite
  - 5: World Class

## 📱 Skill Levels Explained

### 🌊 Beginner
Perfect for those new to swimming or overcoming water fear. Focus on fundamentals, floating, and basic strokes.

### 🏊‍♂️ Intermediate
Build endurance and refine technique. Master all four competitive strokes and improve efficiency.

### 🏆 Pro
Compete at high levels with advanced technique, race strategy, and performance optimization.

### ⭐ Elite
Push boundaries for national and international competitions with comprehensive training programs.

### 🌟 World Class
Olympic-level training with professional support systems and world record ambitions.
